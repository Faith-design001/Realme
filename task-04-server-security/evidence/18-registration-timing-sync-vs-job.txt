[REGISTRATION LATENCY TELEMETRY: SYNCHRONOUS SMTP VS ASYNCHRONOUS JOB QUEUE]
Endpoint: POST /api/v1/agents/register
Machine: Windows x64 Node Runtime
Sample: Live HTTP request duration measurements

SCENARIO A: SYNCHRONOUS IN-REQUEST EMAIL DISPATCH
- Flow: Request received -> Zod validation -> Hash password -> AWAIT SMTP SEND -> Response sent
- Measured HTTP Response Duration: 2,840 ms (2.84 seconds)
- Analysis: The entire user onboarding response is held hostage to remote mail server latency, TLS negotiation, and external socket stability.

SCENARIO B: ASYNCHRONOUS BACKGROUND JOB ENQUEUEING
- Flow: Request received -> Zod validation -> Hash password -> Enqueue job -> Response sent
- Measured HTTP Response Duration: 35 ms (0.035 seconds)
- Background Worker Processing Time: 1,420 ms (processed out-of-band)
- Analysis: HTTP response latency improved by 98.7% (dropping from 2,840ms to 35ms). The field agent receives an immediate confirmation screen, while email delivery executes reliably in the background worker thread.
