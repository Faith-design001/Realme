## 1. Executive Rationale: Security Architecture as Trade-Off Engineering

Engineering security is not a checklist of every possible control; it is the disciplined alignment of defense mechanisms with business operational realities. 

Over-engineering security early in a startup creates excessive operational friction, slows down mobile field workers under harsh outdoor conditions, and drains engineering velocity. Per assessment requirements, this document records **four specific security controls deliberately considered and omitted**, detailing why they were skipped and the exact trigger conditions required to implement them.

---

### Control 1: WebAuthn / FIDO2 Hardware Passkey Authentication
* **What It Is**: Passwordless authentication utilizing physical security keys (YubiKeys) or device biometric authenticators (Apple TouchID / Android BiometricPrompt) based on asymmetric public-key cryptography.
* **Why Skipped at This Stage**:
  1. *Hardware Diversity*: Our 400 field agents in Lekki and Victoria Island operate on diverse, budget Android handsets (Tecno, Infinix, Xiaomi) where hardware-backed biometric Keystores frequently fail or lack WebAuthn browser API support.
  2. *Field Lockout Overhead*: An agent standing on a construction site with dirty or wet fingers cannot complete fingerprint biometrics, causing immediate field lockouts during urgent buyer inspections.
* **Trigger Condition to Implement**: When RealMe expands into high-value institutional commercial escrow transactions ($> ₦2,000,000,000$) where underwriters mandate physical FIDO2 keys for corporate Managing Brokers.

---

### Control 2: Strict Mutual TLS (mTLS) Client Certificate Verification
* **What It Is**: Cryptographic protocol requiring both the server and client to authenticate each other using X.509 digital certificates before an encrypted TCP connection is established.
* **Why Skipped at This Stage**:
  * Implementing mTLS requires deploying and managing a full Public Key Infrastructure (PKI) and installing custom root certificates onto 400 personal agent mobile devices.
  * In a browser-based zero-install web application, mobile browsers handle client certificates poorly, requiring extensive MDM (Mobile Device Management) infrastructure that our decentralized 1099-contractor field agents will not tolerate.
* **Trigger Condition to Implement**: If RealMe establishes a dedicated inter-bank API gateway directly integrating commercial banking settlement servers for real-time escrow sweeping.

---

### Control 3: Mandatory Time-Based One-Time Password (TOTP) Authenticator Apps
* **What It Is**: Requiring a 6-digit dynamic code generated by an authenticator application (Google Authenticator / 1Password) on every login.
* **Why Skipped at This Stage**:
  1. *Onboarding Friction*: 40% of non-technical real estate agents in Lagos struggle with manual QR code scanning and authenticator app sync.
  2. *Device Lost Recovery*: Mobile phone theft and device swapping in Lagos are significant operational factors. Losing an authenticator app without backup recovery keys locks agents out of critical deals for days.
* **Trigger Condition to Implement**: We will introduce optional TOTP for Managing Brokers in Task 05, making it mandatory only if required by NDPC statutory regulatory audits.

---

### Control 4: Captcha / Cloudflare Turnstile on Every Form Submission
* **What It Is**: Automated Turing tests (image puzzles or invisible browser challenge scripts) designed to distinguish humans from automated botnets.
* **Why Skipped at This Stage**:
  1. *Bandwidth Degradation*: Cloudflare Turnstile and Google reCAPTCHA v3 inject 150KB–300KB of third-party JavaScript binaries and establish multiple external socket connections. On congested 3G cellular connections in Lekki, this adds 1,500ms–3,000ms of latency to form submissions.
  2. *Visual Degradation*: Visual puzzle Captchas severely impede visually impaired agents and frustrate mobile users in direct equatorial sunlight.
* **Trigger Condition to Implement**: If our backend anomaly detection logs indicate distributed credential-stuffing attacks originating from rotating proxy IP pools exceeding 100 requests per minute.
